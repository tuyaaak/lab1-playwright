## 3. Playwright ба Selenium

Playwright нь элемент бэлэн болтол автоматаар хүлээдэг. Selenium-д зарим нөхцөлд explicit wait ашиглах шаардлагатай байдаг. Playwright-ийн locator-уудыг ашиглахад тест бичихэд ойлгомжтой санагдсан. XPath ашиглахын оронд role болон test attribute-аар элемент хайсан. Эхний туршилтаар Logout элементийг олоход асуудал гарсан. Алдааны мэдээллээс аль мөр дээр гацсаныг харж зассан. Playwright-ийн HTML тайланд тест бүрийн үр дүн харагдсан. Selenium-г энэ лабораторид тусад нь туршаагүй тул харьцуулалтыг хэрэглэсэн боломжууд болон зааврын мэдээлэлд үндэслэв.
